# Falcon Energy Showcase

Create a premium multilingual demo website for Falcon Oilfield Services, an Oman-based independent oilfield technology company specializing in wireline logging, perforation, well intervention, reservoir monitoring, and technical data solutions.

The goal is to create a high-conversion B2B website demo that feels like a global energy technology company. The website should target oil and gas operators, drilling teams, reservoir engineers, and procurement managers.

Use uploaded UI reference images only as visual direction. Extract spacing, typography hierarchy, image treatment, card style, layout rhythm, and premium tone. Do not copy exact text from the references.

1. Hero section
